## Project

R package to find differentially expressed genes between groups in single-cell RNA-seq with
several subjects per group: one negative binomial mixed model per gene with `glmmTMB`,
`y ~ group + covariates + offset(log(norm_sf)) + (1 | subject)`.

Fork of `yl883/iDESC` (original author Yunqing Liu), maintained by Pablo Villoslada-Blanco.
Canonical repo: `pavillos/iDESC` (`GMEG-CNIO/iDESC` was transferred and redirects here).
Main user: the PDACandDM pipeline (step `03_dea_idesc`).

## Versions

- `v0.2.0` (tag, commit `2be58b9`): the version used by earlier analyses. Must stay installable
  (`ref = "v0.2.0"`) to reproduce them.
- `0.3.0` (branch `v0.3.0`, in progress): breaking release — no `ind_zero`, `zi_model`
  `none`/`constant`, likelihood-ratio test of the group effect, pairwise contrasts, one
  `Status` per gene plus a `gene_status` table, permutation p-values (group label permuted
  between subjects; on by default when the smallest group has < 10 subjects).
  Every user-visible change goes in `NEWS.md`.

## Layout

- `R/`: `iDESC_function.R` (main function), `preprocessing.R`, `normalization_factors.R`,
  `permutation.R`, `data.R`, `sysdata.rda`.

- `README.md` is generated from `README.Rmd`: edit the `.Rmd` and knit.
- `tests/testthat/`: testthat 3rd edition; simulated data in `helper-sim.R`.
- Files that are not part of the package (like this one) must be listed in `.Rbuildignore`.
